# Perceptron — прогноз настроения с механизмом внимания

Учебная нейросеть на чистом Python (без внешних зависимостей) с графическим
интерфейсом: по пяти наблюдениям за днём предсказывает вечернее настроение
по шкале от 1 до 10.

```
Входы (5 токенов) → Внимание (1 голова) → Скрытый слой (3 нейрона) → Прогноз
```

## Архитектура

| Этап | Описание |
|------|----------|
| **Входы** | 5 признаков: сон сегодня (ч), сон вчера (ч), настроение вчера вечером, настроение сегодня утром, тревога с утра |
| **Внимание** | Одна головка self-attention (размерность 4, масштаб √4): токены → Q/K/V → softmax-карта внимания 5×5 |
| **Скрытый слой** | 3 интерпретируемых нейрона: «тело», «эмоции», «тревога» (сигмоида) |
| **Выход** | Сигмоида → прогноз настроения в диапазоне 1–10 |

Скрытые нейроны соответствуют типам входных токенов (маленький type-embedding),
поэтому сеть остаётся полностью интерпретируемой: в интерфейсе видно, какой
нейрон и какой вклад внёс в итоговый прогноз.

## Структура проекта

```
perceptron/
├── main.py        # точка входа
├── app.py         # GUI на tkinter (слайдеры, веса, карта внимания, обучение)
├── perceptron.py  # модель: forward, backprop, обучение, CSV-снапшоты
└── snapshots/     # CSV-срезы состояния сети (в git не входят)
```

## Требования

- Python 3.10+
- Только стандартная библиотека (tkinter, math, csv, dataclasses)

## Запуск

```bash
python main.py
```

## Возможности

- **Прогноз в реальном времени** — двигайте слайдеры входов, сеть пересчитывается мгновенно
- **Визуализация** — схема сети, карта внимания (heatmap 5×5), шкала прогноза
- **Ручная правка весов** — можно редактировать W1, W2 и смещения прямо в интерфейсе
- **Обучение** — укажите фактическое настроение вечером и запустите шаг обучения (backpropagation, включая градиенты через внимание)
- **Пресеты** — быстрый откат к исходным весам
- **Снапшоты** — сохранение полного состояния сети и активаций в CSV (папка `snapshots/`)

## Формат снапшотов

CSV-файл содержит: время, сырые входы, нормализованные входы, векторы после
внимания, все 25 значений карты внимания, пре-активации и активации скрытого
слоя, текущие веса и смещения, вклады в выход, итоговый прогноз.
